# The audit list: everything whose *statement* is checked mechanically.
#
# Single source for two targets:
#
#   make print-assumptions   `Print Assumptions` on every `thm` line, and
#                            CI gates on all of them being closed. The
#                            list reports its own size, so the count is
#                            never duplicated in the workflow.
#   make statements          Snapshot every line's statement into
#                            tools/statements.txt and fail if one moved
#                            without the baseline moving with it.
#
# `thm` lines are printed with `Check` (the statement only, not the
# proof). `def` lines are printed with `Print` (the body, because for a
# definition the body *is* the statement) and carry the definitions the
# two historical statement errors touched -- a weakened `RaoSpread` or a
# degenerate spread condition would show up as a moved statement here
# even though every theorem naming it still compiles.
#
# Adding a theorem: add it here, run `make statements-accept`, and commit
# the baseline in the same commit. A statement that changes without its
# baseline changing fails CI, which is the point.
